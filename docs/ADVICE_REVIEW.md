# N2 starter advice — physician review required

These are editable drafting aids, not clinically validated instructions or medical recommendations. Both doctors must review the English, Marathi and Hindi wording and select advice only when appropriate for an individual patient. No snippet is inserted automatically. Avoid universal fluid/diet/activity instructions: those can be inappropriate for some patients. No dosage guidance was seeded.

The migration seeds 20 entries per language for each existing doctor (60 per doctor). Each doctor can edit/delete their own entries under Notes and advice → Advice snippets → Manage advice. Deleted snippets are not recreated on ordinary visits. A new doctor can explicitly add the starter library. Explicit seeding preserves existing edits by stable IDs; it can restore deleted starter entries.

Review status: NOT YET physician/translator approved. Review equivalents for literacy, local language and clinical appropriateness before relying on them.
