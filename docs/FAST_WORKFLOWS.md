# Fast repeat-patient workflows

- Tap Search patients in the header, or press Cmd/Ctrl+K anywhere in the dashboard. Search is debounced and scoped to the current doctor, using the existing name/phone/diagnosis/medicine search. Tap a result to open it.
- In the medicine entry form, choosing a medicine focuses dosage. Enter from a text field adds the selected medicine once dosage is filled. Composition events (including Marathi typing) do not submit early.
- Rx edits autosave after 800ms to a doctor-owned cloud draft. Each patient entry URL, duplicate-source URL and generic new-Rx page has its own draft key. Reopening the same entry restores patient, diagnosis, medicine details, notes and measurements; a restored banner is shown. Drafts are not created as visits or prescriptions. Saving the prescription clears its draft after any queued autosave finishes. Incomplete measurements can be saved as text and are checked before final Rx save.
- Drafts contain medical information and are kept in the clinic DB, not browser localStorage. All draft actions verify the doctor and any selected patient's ownership. RLS and grants deny direct Data API access. Sign-out/unmount clears the in-memory builder after flushing pending edits; closing the browser before a save completes can lose the latest edits. Watch the save status; failed saves ask you to keep the page open. Paper size is a print preference and starts at A5 when reopening.
